# docker automation
If you just need to download data and don't want to dive into nightmare of installing proper versions
of everything, building and installing stuff, then you in a right place

install docker and docker-compose

execute `docker-compose.yml`

`docker-compose up`

it will install all required versions of packages and python stuff into container.
Then it will run `run.py` file. 
In here you can create a dataset and tell it to download files if missing and say where to download.
